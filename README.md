# Pocket Game Night

An installable, offline-capable web app that helps friends and families run in-person party and card
games from one phone. It keeps the social ritual and takes away the paper and the bookkeeping.

First game: Tambola (Housie).

Status: Phase 0 (foundation). Nothing playable yet.

Project rules for contributors, human or AI, are in [CLAUDE.md](CLAUDE.md).
