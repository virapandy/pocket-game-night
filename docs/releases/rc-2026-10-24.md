# Pocket Game Night 1.4.0 (release candidate rc-2026-10-24)

A new game, **Secret Words**: two teams, one board of words, and a clue giver for each team who sees the secret map
and gives one-word clues. Tambola and Impostor play as in 1.3.1.

## For the host
- **Secret Words** on "Host a game": set up players and teams, choose one, two or three phones, the Full or Easy board and
  the Landmine rule, then play a whole game night with Play again, End for tonight and a summary of the night.
- **The map stays private:** the board on the host phone never shows which team a word belongs to until it is turned over.
  The clue giver sees the map behind a tap, on the host phone or on their own phone ("Join a game" with the host's code);
  it hides when the phone is put down, when the app is left, and after a minute untouched.
- **History** keeps each game night, with its games and clue givers.
- **Report a problem** now opens the phone's share sheet (or copies the report where there is none); the app never sends
  anything by itself. A report started during a game waits until the game ends.
- **Buttons look ready at once** on every Secret Words screen; a tap in the first moment is still ignored, so a double tap
  never skips a step.
- Home and "What shall we play?" show their cards side by side with the phone sideways.

## Also in this release
- Version 1.4.0. Saved games, tickets and sessions from earlier versions still open. Secret Words saves its game nights in
  the same versioned format; the map phone's saved map carries its own version.
- Settings opened from a game is labelled "Game settings".

## Testing for this release
- Every rule test, and every Secret Words, Impostor and Tambola browser test on Android and iPhone (complete run on this
  candidate). Secret Words' privacy checks run on every room screen at every step, on both phones.
- 60 simulated table games (an AI clue giver, Jev guessing) and 40 screen-played game nights as six personas, 10 with Jev
  choosing: no privacy slips, no stuck moments. Six pretend players played whole game nights on five phone sizes; their
  layout findings are fixed in this candidate. Android emulator run green. Every change passed the AI reviewer before merge.
- Mutation testing (report only) has no Secret Words group yet; it is set up after this release, and the next release
  includes it. The Secret Words rules had 900+ rule tests, property tests and a reviewer pass before merge.
